Problem: which route is best for a drone?

A drone flies from A(−1, 0) to B(1, 0) through wind F. Work done by the wind = ∫ F · dr. Positive means the wind helps; negative means the drone fights it.
Method: parametrize the path x(t), y(t) → dot F with dr → integrate over t.
Octave: I = int(dot(F, dr), t, a, b)

Problem: how does a vehicle bounce after a pothole?

Spring + shock absorber: m x″ + c x′ + k x = 0, with x(0) = 0 and x′(0) = v₀ (the speed the bump gives it).
Method: auxiliary equation m r² + c r + k = 0 → check the roots (distinct, repeated, complex) → write the solution → apply x(0), x′(0).
Octave: dsolve(...) or the variation of parameters code.

Problem: where does the pollution go?

Pollution in a river of speed a follows ut + a ux = 0. Separation of variables u = X(x)T(t) gives u = A eλ(at − x), a pattern that slides downstream at speed a.
Curve = pollution level along the river (A = 1). Dashed line = level 1. The orange dot, where the level equals 1, travels at speed a.
Steps: T′ = aλT ⇒ T = T₀eaλt; X′ = −λX ⇒ X = X₀e−λx; u = A eλ(at − x)
Octave: dsolve for each ODE, then multiply.
